Extension: Applied Requirement Standard

Official URL: https://openanimalnutrition.org/fhir/animal-nutrition/StructureDefinition/applied-requirement-standard Version: 0.1.0
Draft as of 2026-10-26 Computable Name: AppliedRequirementStandard
Other Identifiers: OID:2.16.840.1.113883.4.642.40.1004.42.2

Which published requirement standard the adequacy check was run against, by its edition's code when the edition is known (for example AAFCO-2026). A variable selection, never hardcoded into the check.

Context of Use

    This extension may be used on the following element(s)

    • Element ID: Observation

Usage info

Usages:

  • Use this Extension: Animal Nutrient Adequacy Assessment
  • Examples for this Extension: Observation/ExampleAdultMaintenanceAdequacy and Observation/ExampleRestrictedMaintenanceAdequacy
